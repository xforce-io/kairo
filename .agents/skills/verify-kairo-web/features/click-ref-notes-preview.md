# #433 左侧点击参考进入 notes 预览

Drive **主题页左侧参考**（`/w/{slug}?ref={id}` 的 `hx-get`，带 `panel=notes`）。中间区换成该参考的 notes 预览。置顶展开仍只认已发布规则，本票不写 `note-pin.json`。不碰现网 serve root。不触发 LLM / `step` / `compose`。

## 入口

1. Topic `/w/{slug}` 左侧点击一条参考
2. 同一选中地址刷新后，右侧元信息加载仍请求 `panel=notes`
3. 空预览上的「回到摘要」请求不带 `panel=notes`，回到该参考的摘要主预览

**不走：** 改置顶写入、删除回退、机器再生成；Ref 详情 `/refs/{id}`；无 note 时自动新建 note。

## 路径 → 可判定结果

| # | 路径 | 可判定结果 | 依赖 |
|---|---|---|---|
| S1 | 同一参考至少两条正文不同，且没有人工置顶；左侧点击 | 中间区进入 notes 预览，展开区正文是追加序更早的一条，没有任何「已置顶」 | Console |
| S2 | 至少两条正文不同，人工置顶的是较晚那条；左侧点击 | 展开区正文仍是该条，且只有这一条显示「已置顶」；置顶文件不变 | Console |
| S3 | 没有 note；左侧点击，再点「回到摘要」 | 中间区没有 note 正文，可见可用的「回到摘要」；使用后主预览出现「摘要」；不新建 notes 文件 | Console |

## 已知不做

- 不改已发布的置顶数量、设置与展开选择
- 不在无 note 时插入占位 note
- 直接打开 `/w/{slug}/ref/{id}`（无 `panel=notes`）仍是摘要主预览，供回到摘要使用
